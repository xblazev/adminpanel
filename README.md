# AdminPanel

Aplikasi admin dashboard berbasis Vue dan Vuetify dengan halaman login, layout utama, routing dasar, serta konten contoh untuk fondasi pengembangan berikutnya.

## Menjalankan project

```bash
npm install
npm run dev
```

## Alur awal

- Buka halaman login.
- Isi form dengan nilai apa pun untuk masuk.
- Setelah login, pengguna diarahkan ke dashboard.
- Tombol logout akan mengembalikan pengguna ke halaman login.
